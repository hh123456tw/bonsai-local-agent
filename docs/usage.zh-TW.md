# Bonsai 修正版

2026-11-03；RTX 3080 12GB、Windows、OpenCode CLI 2.2.5。

## 使用

1. 點桌面「Bonsai OpenCode 修正版」。
2. 選擇要工作的專案資料夾。啟動器會載入模型，再進入 OpenCode CLI。
3. 使用 Build；模型顯示 Bonsai 27B Guarded 32K。
4. 不使用時點「停止 Bonsai」，釋放模型顯存。關閉 CLI 本身會保留推論服務，方便下次快速連線。

程式、模型與設定都在 `C:\AI\bonsai`。Strata 的程式與捷徑保留。這套設定不載入 Orca。

橋接層會剝除舊的 reasoning 欄位並設定 preserve_thinking=false。若模型再次要求連續兩次已執行的同一工具，先要求改用不同方法，最多重試兩次；仍無進展時明確回報失敗。本輪工具超過 24 次也會停止。停止不代表任務成功。

橋接層先收齊一輪生成再檢查，因此畫面可能等到這輪思考及工具指令完成才更新；不是逐 token 即時顯示。

## 排查

- 啟動失敗：查看 `C:\AI\bonsai\engine.log`。
- 模型重複、停止或代理錯誤：查看 `guard-events.jsonl` 與 `proxy.log`。
- 顯存不足：先卸載其他推論程式已載入的 GPU 模型，再啟動；啟動器不會自行關閉 Strata。
- 初次路由校準可能多等約 40 秒；獨立快取保存在 `routes.json`，快取建立後，停止到重新可生成實測約 8.42 秒。

驗證摘要見同目錄 `Bonsai修正版驗證.json`。
